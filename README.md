# Spellixir

Spellixir is a free, Apache-2.0-licensed Elixir plugin for JetBrains IDEs. Its runtime-independent Native Core provides `.ex` and `.exs` recognition, syntax highlighting, tolerant parsing, and Mix-project detection without requiring Elixir or Erlang/OTP.

The Supported Hosts are IntelliJ IDEA, GoLand, and PyCharm. See [release gates](docs/release-gates.md) for the tested build range, compatibility claims, packaged smoke tests, and release procedure.
